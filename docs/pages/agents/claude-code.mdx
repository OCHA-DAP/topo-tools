Install the [`topo-tools`](https://github.com/OCHA-DAP/topo-tools/blob/main/plugins/topo-tools) plugin to clean, code, and package COD-AB administrative boundary polygons. Follow the tab for the Claude Code setup in use.

<Tabs>
<TabItem label="VS Code (Claude Code panel)">


1. [Click here](vscode://anthropic.claude-code/install-plugin?plugin=topo-tools&marketplace=https%3A%2F%2Focha-dap.github.io%2Fcod-site%2Ftools%2Fmarketplace.json), allow the browser to open VS Code, confirm adding the marketplace, then select **Install for you**.
2. Turn on automatic updates. In VS Code, select **File > Open File** and open the user settings file:

    - **Windows:** `%USERPROFILE%\.claude\settings.json`
    - **macOS:** `~/.claude/settings.json`

    Add `"autoUpdate": true` to the `topo-tools` entry, with a comma on the line before:

    ```json {6-7}
    "extraKnownMarketplaces": {
      "topo-tools": {
        "source": {
          "source": "url",
          "url": "https://ocha-dap.github.io/cod-site/tools/marketplace.json"
        },
        "autoUpdate": true
      }
    }
    ```

</TabItem>
<TabItem label="Terminal (claude command)">


1. In a Claude Code session, run:

    ```text
    /plugin install topo-tools --marketplace https://ocha-dap.github.io/cod-site/tools/marketplace.json
    ```

    Confirm adding the marketplace, then select **Install for you**. If Claude Code shows `Run /reload-plugins to activate`, run it.

2. Turn on automatic updates: run `/plugin`, open the **Marketplaces** tab, select **topo-tools**, then select **Enable auto-update**.

</TabItem>
</Tabs>

3. Open an empty folder and run `/topo-tools:cod-ab`.

## Without the plugin

If the plugin install fails (for example, a network filter blocks ocha-dap.github.io), open an empty folder and paste this prompt into Claude Code:

```text
Download https://raw.githubusercontent.com/OCHA-DAP/topo-tools/main/plugins/topo-tools/skills/cod-ab/SKILL.md verbatim with curl (Invoke-WebRequest on Windows), not a summarizing web fetch, then follow it.
```
